# エコ・ブレイカー (Eco-Breaker)

---

## 1. 基本情報
* **コンセプト**: 世界線同期バフを活かす「無限生態系操作」ローグライクRPG。
* **テーマ**: 「管理（調和）か、破壊（絶滅）」を選択するエコロジカルなジレンマ。
* **開発言語**: HTML5 / CSS3 (Vanilla CSS) / JavaScript (ブラウザで開くだけで今すぐプレイ可能)

---

## 2. 盛り込まれた高度なゲームシステム

### ① 【新】ヘッダー統合型 SYSTEM CONTROL & セリフ風ログウィンドウ
画面配置をさらにスマートに整理し、RPGらしい没入感を高めました。

* **SYSTEM CONTROL のヘッダー統合**:
  * ゲームプレイを妨げないよう、**「最初からやり直す (引き継ぎ)」**、**「世界線リセット」**のコントロールボタンを画面最上部のヘッダーにスマートに統合しました。
  * 左サイドバーから不要な操作用パネルを削除し、ステータス画面をスッキリさせました。
* **セリフ窓風ログウィンドウ (Dialogue Log)**:
  * 従来の右サイドバーのログパネルを廃止し、中央メインエリアの **CURRENT FIELD（ビジュアルエリア）のすぐ真下に「ゲームのセリフ送り窓」風のデザインで統合** しました。
  * レトロアドベンチャーゲームのように、「▶」のインジケータ付きで直近のログが3〜4行でスクロール表示され、戦闘中の攻防やイベントがセリフのように臨場感たっぷりに流れます。
* **スリムな右サイドバー**:
  * ログが中央に移動したことで、右サイドバーは「ECOSYSTEM MONITOR」（スライム、魚人、ゴブリンの生息数）のみを監視する専用モニターに特化し、画面のバランスが向上しました。

### ② プレイヤー主導のゲーム進行＆無限探索システム
ゲームはプレイヤーを強制的にゲームオーバー画面に遷移させず、いつでも意思を持って探索を続けられる仕様に進化しました。

* **HP 0 時の緊急自動蘇生**:
  * 戦闘中にHPが0になっても、ゲームオーバー画面での終了はありません。
  * 監視者システムの緊急自動再起動が走り、**所持ゴールドを半分失う代わりにHPが50%まで復元され、探索を続行**できます。
* **20ターン調和の到達ボーナス**:
  * 絶滅0のまま20ターン目を迎えると、「調和の実績」ログが流れ、ボーナス資金（+200G）を獲得した状態で、21ターン目以降も無限に探索を続けられます。
* **腐敗度 100% のアポカリプス徘徊モード**:
  * 腐敗度が100%に達すると、世界崩壊警告と共に背景が混沌の荒野に固定され、ボス「アポカリプス」が野生で超高確率（60%）で出現する世紀末フィールドへと突入しますが、その状態でも探索を続けられます。アポカリプスを撃破すると「虚無の覇王」となり、ショップ商品が実質永続無料になるボーナスが発生します。

### ③ 「古代の隠し洞窟」発見イベントと新種（全42種）
* **洞窟発見イベント**:
  * 周辺探索時、15%の確率で「古代の隠し洞窟」への入り口を発見します。
  * 発見すると、洞窟の奥から漂う魔力を感知し、即座に隠し新生物のいずれかとエンカウントします。
* **追加された新野生モンスター**:
  * **ストーンスパイダー (Stone Spider)**: 岩石の甲殻を持つ蜘蛛。捕獲可能。
  * **ジュエルスライム (Jewel Slime)**: 宝石を体内に宿した希少スライム。撃破時に高額ゴールドをドロップ。捕獲可能。
  * これら2種が図鑑に加わり、図鑑の最大数は **「全42種」** となりました。
  * これらも捕獲するまでは「CAPTURED CAGE」に枠すら現れないシークレット仕様です。

### ④ 機能ごとの中央表示画面の完全切り替え (View Switching)
ゲームの状態（フェーズ）に応じて、中央の「CURRENT FIELD」エリアの表示がグラフィカルかつ完全に切り替わります。

* **探索画面 (Explore View)**: 通常移動・風景表示。
* **戦闘画面 (Battle View)**: 敵グラフィック（CSSドットスプライト）とHPゲージをオーバーレイ表示。未発見時は名前が「？？？？」にマスクされます。
* **闇の商人画面 (Merchant View)**: 商人の姿とセリフテキストを表示。
* **生態系操作画面 (Ecosystem View)**:
  * 中央フィールド内に「CAPTURED CAGE」がグラフィカルに出現。
  * **スライム、魚人、ゴブリン以外の隠し捕獲種は、初めて捕獲成功（図鑑に登録されるかストックが1以上になる）するまで表示されず、捕まえられない変異種などは最初からケージに現れません。**

### ⑤ 「環境の引き継ぎ」によるローグライク・ループ
* **仕組み**: 絶滅させた種族データがブラウザ（`localStorage`）に記録され、次の周回で最初から砂漠化・干上がった湖底などの環境へ変化します。プレイヤーには初期攻撃力バフが引き継がれます。

### ⑥ シナジー・アーティファクト（特化ビルド）
探索や戦闘、闇の商人から手に入るアーティファクトを組み合わせることで、極端なパラメータを持つ特化ビルドを構築できます。

| アーティファクト名 | 獲得方法 | 効果内容 | ビルド・シナジー例 |
| :--- | :--- | :--- | :--- |
| **グラスキャノンの核** | 闇の商人 (100G) | 攻撃力+50 / 防御力-20 | 一撃必殺を狙う「特攻ビルド」 |
| **瘴気のベール** | 闇の商人 (150G) | 毎ターンHP-5(毒) / 与ダメージ2倍 | 常にHPが減り続けるハイリスク・ハイリターン |
| **毒素伝染 of Core** | 闇の商人 (120G) | 毒ダメージを受けた際、その2倍を敵に反射 | **【瘴気のベール】と組み合わせることで、毎ターン敵に自動的に10ダメージを反射するシナジーが発動** |
| **背水のガラス** | 闇の商人 / 変異種 | HP20%以下で攻撃力3倍 & 防御力+30 | ピンチ時に驚異的な耐久と攻撃力を得る「起死回生ビルド」 |
| **保護者の紋章** | 闇の商人 (90G) | 生存している種族数 × 10、防御力アップ | 絶滅を一切行わない「調和ルート」の攻略をサポート |
| **生命の種子** | 闇の商人 (80G) | 毎ターンの探索進行時にHPが 5 回復 | 自傷毒ビルドの相殺や、調和ルートの延命に役立つパッシブ |
| **混沌の魔眼** | 闇の商人 (140G) | 攻撃時、世界の腐敗度の数値分の追加ダメ加算 | **絶滅を行って腐敗度が上がるほどプレイヤーの火力が跳ね上がるシナジー** |
