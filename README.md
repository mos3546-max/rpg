## 2. 盛り込まれた高度なゲームシステム

### ① 【新】ドラゴンクエスト風 伝統的UI＆メッセージシステム
グラフィックとメッセージの語り口を、**『ドラゴンクエスト』をリスペクトした本格的なレトロドットスタイル**にフルリニューアルしました。

* **漆黒のバトルウィンドウと白の二重線枠**:
  * 全体の背景色を完全な漆黒（`#000000`）に変更。
  * 各パネルやメッセージウィンドウには、伝統的な **「二重の白線（ダブルボーナー枠）」** を施し、ゲームキャビネットとしてのノスタルジックな一体感を高めました。
* **ホバー時の選択肢カーソル（▶）と白黒反転**:
  * コマンドボタンを左寄せに統一。ボタンにホバーした際、**文字と背景色が白黒反転**し、先頭に「▶」のカーソルが出現する伝統のコマンド選択演出を再現しました（ボタンの切り替えアニメーションをあえて排除し、レトロゲーム特有の「即時入力」に調整）。
* **ドラクエ風スペース空きメッセージ**:
  * セリフログ窓に流れるテキストを、ドラクエの戦闘ログをリスペクトした仮名混じりのテキストに変更。
    * *戦闘開始*: `「スライムが　あらわれた！」`
    * *攻撃*: `プレイヤーのこうげき！　「スライム」に　12のダメージ！`
    * *撃破*: `「スライム」を　たおした！　20ゴールドを　てにいれた！`
    * *死亡時*: `プレイヤーは　しんでしまった！　しかし　ふしぎなちからで　いきかえった！`
* **丸みを排除したカクカクCSSドットスプライト**:
  * スライム、ギョジン、ゴブリンなどの全エネミーグラフィックを、円形ポリゴンから **「角を完全にとがらせた、カクカクのレトロドットスプライト」** にCSSアートを一新。目の瞳なども四角形のピクセル表現に生まれ変わりました。

### ② 弱肉強食・自動生態系シミュレーション
プレイヤーの介入だけでなく、野生魔物や人間勢力が**ターン経過によって自律的に争う「弱肉強食・食物連鎖」のシミュレーション**がバックグラウンドで毎ターン作動します。
* **自然繁殖**: 生存している野生種は、毎ターン `20%` の確率で自然に分裂・増殖します。
* **捕食活動**: 飢えたゴブリン（`18%`）やギョジン（`12%`）が野生のスライムを捕食し、数を減らします。
* **飢餓連鎖**: スライムが野生からいなくなると、ゴブリンやギョジンは飢餓状態になり、毎ターン `22%` の高確率で餓死して連鎖滅亡へと突き進みます。
* **縄張り争い**: ゴブリンとギョジンが共に生存している時、`12%` の確率で小競り合いが発生し、双方の生息数が削られます。
* **ギルド巡回**: 腐敗度が20%を超えると、人間（討伐隊）が魔物を巡回討伐し、野生数を減らす代わりに世界の腐敗度が `4%` 回復（低下）します。
* **檻（ケージ）内暴動**: 捕獲檻の中に「モンスター」と「人間」を同時に閉じ込めている場合、檻の中で人間が暴れてストック魔物を討伐（消滅）してしまいます。

### ③ プレイヤー主導の無限探索システム
* **HP 0 時の緊急自動蘇生**: 所持金を半分失う代わりにHPが50%まで復元され、探索を続行。
* **20ターン調和の到達ボーナス**: 絶滅0のまま20ターン到達でボーナス資金（+200G）を獲得。
* **アポカリプス徘徊モード**: 腐敗度が100%に達すると、ボス「アポカリプス」が野生で超高確率（60%）出現する世紀末フィールドへ突入。討伐時はショップ全品無料化バフを獲得。

### ④ 「古代の隠し洞窟」発見イベントと新種（全42種）
* **洞窟発見イベント**: 通常探索時、15%の確率で「古代の隠し洞窟」を発見し、即座に隠し新種「ストーンスパイダー」または「ジュエルスライム」とエンカウント。これらは捕獲するまで檻のスロットすら現れないシークレット仕様です。
